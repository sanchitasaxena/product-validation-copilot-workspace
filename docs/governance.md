# Governance

## Source grounding

Generated content should identify whether it is:

- catalog-backed,
- source-backed,
- user-provided assumption,
- AI-inferred assumption,
- to be discovered,
- validated finding,
- proposed catalog update.

## Target Audience Catalog governance

The local target audience index should be treated as a managed snapshot. Refreshes from SharePoint or Microsoft Graph should be reviewed before replacing local records.

## QA governance

The original RAUC bug tracker is the canonical real-world QA style corpus. Preserve engineering-authored scenario patterns when generating new trackers.

## Human review

The tool can recommend, draft, classify, and validate. Humans approve:

- official audience changes,
- study scope,
- recruiting criteria,
- UXR intake,
- release-readiness decisions,
- final artifact edits.
