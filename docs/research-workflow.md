# Research Workflow

Research workflows include:

- research planning,
- discovery interviews,
- concept-framing research,
- moderated usability guides,
- unmoderated testing guides,
- discovery surveys (built via the `discovery-survey` workflow),
- handing raw evidence to Product Designer Bootstrap or Automation UXR for synthesis,
- Monday.com UXR request answer drafting.

All listed generation workflows are executable today and can ingest a pre-authored context or local PRD/RFC documents. Research artifacts produce JSON plus DOCX. Discovery surveys also produce a Microsoft Forms Quick Import DOCX, structured JSON/CSV, and transfer instructions. The workspace does not publish forms or submit Monday.com requests. See `research/README.md` and `examples/research-source-intake/`.

## Audience mode

Use catalog-grounded mode when known persona/JTBD/CUJ context exists.

Use discovery mode when audience context is unknown or is the subject of the research.

## Evidence discipline

Research outputs should preserve:

- source documents,
- participant quotes where available,
- evidence strength,
- assumptions,
- conflicting signals,
- recommendations bounded by evidence.
