# Create Discovery Guide Workflow

Use this workflow when persona, JTBD, CUJ, workflow, or mental model context is unknown or being validated.

## Steps

1. Capture product area, suspected role, problem space, and decision.
2. Label audience assumptions as draft or to be discovered.
3. Write open-ended questions that surface behavior and mental models.
4. Avoid usability task wording unless a known workflow exists.
5. Include synthesis prompts for promoting validated findings into proposed catalog updates.
