# Create Testing Guide Workflow

Use this workflow for moderated or unmoderated research testing, not internal QA.

## Steps

1. Confirm catalog-grounded audience context or source-backed role context.
2. Confirm product/version/environment under test.
3. Map each task to a JTBD/CUJ or known workflow.
4. Write task prompts that observe user behavior without telling users where to click.
5. Include observable success criteria and facilitator notes.

If audience context is unknown, route to discovery mode first.
