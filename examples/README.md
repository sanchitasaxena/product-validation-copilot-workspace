# Examples

Examples should show real or realistic product validation workflows.

## Current reference examples

- `synthetic-reference/`: synthetic, non-confidential end-to-end reference run from local target audience resolution to generated QA bug bash tracker.
- `project-qa-bug-bash-pilot/`: synthetic, non-confidential reference run for the reusable Project QA Bug Bash Pilot Workflow.
- `source-document-intake/`: synthetic Markdown, text, and DOCX inputs plus a complete source-driven QA workflow output.
- `research-source-intake/`: synthetic PRD input plus a complete source-driven research workflow output (testing guide / discovery guide), including existing-vs-new JTBD/CUJ cross-referencing against the Target Audience Catalog.
