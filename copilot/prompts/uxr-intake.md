# Monday.com UXR Request Prompt

Use this prompt to draft answers for the Monday.com UXR request form from a research context package.

## Required fields

- Study name
- Product area
- Research type
- Decision this research informs
- Primary persona
- Secondary personas
- JTBD/CUJ or discovery-mode statement
- Timeline/deadline
- PM
- Primary contact
- Recruiting constraints
- Source docs

## Rules

- Do not submit the form. Generate an answer sheet and stop.
- Ask one focused question at a time for required fields that cannot be inferred.
- If audience context is discovery-mode, state that the research goal is to discover or validate persona/JTBD/CUJ.
- Flag missing fields rather than guessing.
